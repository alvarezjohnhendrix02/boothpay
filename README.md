# BoothPay

Booth sales app for the SPCIS Media Arts Club. Works offline on phones and syncs to a Google Sheet.

- Open the site → **I'm selling at a booth** or **I'm the moderator**.
- Moderator: connect the Google Sheet with `docs/SYNC_SETUP.md`, then send the setup file to each booth phone.
- Plain HTML/CSS/JS, no build step.

Fonts: Varela Round, IBM Plex Mono and Shoulders Display are used under the SIL Open Font License 1.1 (https://openfontlicense.org). See `assets/fonts/FONTS.md`.
